## 四个行为复审域

### `feature.foundation-platform.platform-paths`

- 新证据：Windows 包身份新增 `OpenAI.ChatGPT-Desktop`，`app_id` 仍为 `App`。
- 复审重点：Windows 检测路径扩展不能改变 macOS 等价语义，也不能暴露用户绝对路径。
- 目录动作：更新来源证据与 Windows 语义；不实现上游启动器。

### `feature.session-data.local-session-management`

- 新证据：支持 `CODEX_SQLITE_HOME`，并在合法目录存在时作为 SQLite 根目录。
- 新证据：删除会话可覆盖多个数据库，产生组合 undo token；撤销前必须对全部数据库和文件做预检。
- 新证据：撤销只允许写回已批准数据库路径；撤销成功后刷新列表，删除期间保留撤销窗口。
- 目录动作：更新输入、输出、副作用、失败语义和 Windows/macOS 一致性；fixture 只使用合成路径和数据。

### `feature.plugin-script.dream-skin-library`

- 新证据：本地主题配置新增可选 companion 图片，限制为 `png/jpeg/webp/gif` 的 base64 data URL，并包含宽度、侧边和偏移参数。
- 目录动作：只把安全、可移植的本地配置能力纳入 library 合同与 fixture；不复制上游 TypeScript。

### `feature.plugin-script.dream-skin-runtime` 与 `feature.plugin-script.renderer-enhancements`

- companion 的实际显示依赖 renderer 注入、DOM 定位和注入脚本版本升级。
- 两个功能继续保持 `exception-pending`；本 Issue 只补充来源与例外理由，不把 JavaScript、WebView、CDP 注入或上游 UI 迁入产品。
- 若未来要保留等价用户能力，必须另建功能或一致性例外 Issue，由项目所有者决定 Rust/Iced 原生替代语义。
